=====================================================
  KENSHI CO-OP  -  SETUP GUIDE  (version 0.1.33)
=====================================================

One file sets everything up: KenshiCoop-Setup.exe
It takes about 2 minutes. You only do this once.


-----------------------------------------------------
  BEFORE YOU START
-----------------------------------------------------

  [ ]  Kenshi is installed on Steam
  [ ]  Steam is open and signed in
  [ ]  Kenshi is CLOSED


-----------------------------------------------------
  STEP 1 - Download
-----------------------------------------------------

  Download KenshiCoop-Setup.exe.

  If Google Drive or your browser says the file
  "can't be scanned" or "isn't commonly downloaded",
  click  Download anyway  or  Keep.


-----------------------------------------------------
  STEP 2 - Run it
-----------------------------------------------------

  Double-click KenshiCoop-Setup.exe.

  A blue box may say "Windows protected your PC".
  That only means the file is new. Click:

        More info   ->   Run anyway

  If your antivirus blocks it, send me a screenshot.


-----------------------------------------------------
  STEP 3 - Install
-----------------------------------------------------

  A small "KenshiCoop Setup" window opens.
  It should say "Kenshi found:" and show your Kenshi folder.

  Click  Install.

  It backs up your saves first (about a minute), then
  installs everything. When it says
  "KenshiCoop is installed", click  OK.

  That's it - you're set up.


-----------------------------------------------------
  STEP 4 - Check it worked
-----------------------------------------------------

  1. Start Kenshi from Steam like normal.

  2. A small Kenshi window opens first. On its Mods tab,
     only  KenshiCoop  should be ticked. Click  OK.

  3. On the main menu, look at the bottom-right corner.
     It should say:

        RE_Kenshi 0.3.5 - Kenshi 1.0.65

  If you see that, everything worked.


-----------------------------------------------------
  PLAYING TOGETHER
-----------------------------------------------------

  Everyone needs this same version (0.1.33).

  JOINING A FRIEND'S GAME
    1. Start Kenshi and stay on the main menu.
    2. Press  F2  and type your name.
    3. Choose  Client  and  Steam.
    4. Paste the Steam ID your friend sends you.
    5. Click  Connect.
    You get their world automatically - don't load a save.

  HOSTING
    1. Start Kenshi and stay on the main menu.
    2. Press  F2  and type your name.
    3. Choose  Host  and  Steam.
    4. Click the button to copy your Steam ID and send it
       to your friends.
    5. Click  Create session, then load your world.


-----------------------------------------------------
  ALREADY HAVE AN OLDER VERSION?
-----------------------------------------------------

  Just run the new KenshiCoop-Setup.exe and click
  Install. It updates in place and keeps your settings.
  No need to uninstall first.


-----------------------------------------------------
  IF SOMETHING GOES WRONG
-----------------------------------------------------

  Take a screenshot of any message you see and send it
  to me. If the setup stops partway, nothing in your
  game has been changed.

  Your save backup is in:
      Documents  >  KenshiCoop backups


-----------------------------------------------------
  TO REMOVE IT
-----------------------------------------------------

  Run KenshiCoop-Setup.exe again and click  Uninstall.
